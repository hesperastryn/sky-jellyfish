A colossal luminous jellyfish rises over a sleeping city at night, its cyan-and-magenta bell glowing against a deep indigo sky while its tentacles stream behind it and three tiny figures watch from a rooftop below. The image is drawn entirely procedurally with Python and PIL — layered radial gradients for the bell, tapered cubic-bezier ribbons with an additive glow pass for the tentacles, and a hand-placed skyline, crescent moon, stars and rising light particles — rendered at 2048x2048 and downscaled to 1024x1024 by `generate.py`. There is no text in the image; the single bold silhouette is designed to read clearly even at thumbnail size.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
